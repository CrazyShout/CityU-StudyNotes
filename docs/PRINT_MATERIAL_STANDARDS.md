# 三册学习讲义的写作与打印规范

更新：2026-10-16。本文汇总截至本日已确认的要求，供后续编写、审阅和协作使用。它是维护规范，不是学生正文，也不表示每一讲已完成全部改造。各轮完成情况、未解决项和验收证据另记在`docs/reviews/`。后续用户的新要求优先；本规范中的长期原则与某一轮的实施范围要分开。

## 写作时先记住这几件事

我们要的是能从头学习的整讲讲义：顺着老师的课讲清楚，读完能处理题目，复习时又容易找回要点。它不只是PPT缩写，也不只是零散知识点汇总。

- **忠实于课程主线。** 原课的顺序、例子、符号和任务决定内容组织；通俗化是补上理解过程，不是另编一门脱离老师的课。
- **先让读者知道发生了什么。** 交代对象、已知信息和要解决的问题，再谈模型、公式和限制。
- **讲完整的一个例子。** 数据与情境尽量连贯，解释每一步为什么这样做；需要时配图，再回到正式表达和课堂原例。
- **不讲废话，不要AI味。** 用自然、具体的语言讲知识，删除空话、套话、重复总结和生硬包装；术语要解释、推理不跳步，幽默只在帮助理解时使用。
- **正文讲知识，维护文档记制作过程。** 出处要能查，但不让来源代码、版本盘点和核查声明挡住讲解。
- **中文理解，英文能答。** 中文串讲、英文术语、对齐的双语题答；不为了全文翻译把内容重复一遍。
- **重点与难度分开。** 历史试卷说明曾经怎样考，不能据此预测必考；复习提示短而准确。
- **纸上也能独立使用。** 题图、条件、公式、答案和返回页码齐全，不能依赖点击展开或另找一张课件。

后文分别规定内容、版式、考试提示和验收；不是要求每篇正文照抄这些栏目。

## 2. 内容：让初学者顺着老师的课学懂

### 2.1 目标、范围和教学顺序

读者是从基础开始学习、需要应对英语授课和英语考试的PhD学生。讲义应帮助他理解老师整讲的逻辑、完成配套任务，再通过已有卡片巩固；不能让卡片替正文填解释漏洞。

当前Canvas材料决定本学期内容。历史课件、往年试卷、同学小抄和教材用于辅助理解与复习，必须保留各自身份；不把历史资料补成尚未下载的当前课程要求，也不把历史题目范围当成已确认的QE范围。

Lecture／Chapter沿老师实际授课顺序组织，保留重要英文标题、符号、原例、图和代码约定。重复演示可合并，但每个原教学单元仍须在覆盖索引中找到位置。Notebook与PDF重复导出不重复计算覆盖；网络课完整版本与part副本要核对差异。未提供的Tutorial或Assignment明确记为未提供。

没有录音或明确文字依据时，只能说“根据材料归纳的主线”，不能声称老师口头强调过某点。不同年份的共享协方差、逐类协方差等模型不得混用。

### 2.2 连续讲解，而不是碎片卡片堆叠

一讲开头交代本讲要解决什么问题、与前面知识的关系、读者需要什么基础以及学完能做什么。概念讲解遵循以下思路，但不强制每节重复同一组栏目：

1. 先把对象、手头信息和任务讲完整；读者应知道现在究竟在判断、计算或实现什么。
2. 允许一个直观的做法，再用具体例子说明它哪里不够。
3. 为解决眼前困难引入概念，先解释用途，再给英文术语、定义和公式。
4. 沿同一组数据走完主要步骤，说明为什么这样算，再总结一般方法与条件。
5. 回到老师的原例、符号或代码，让读者能认出课堂对应内容。
6. 用改变数字、条件或情境的独立小题检查同一种能力，然后链接配套任务与少量已有复习卡。

老师的例子易懂时优先讲清原例；确有理解障碍时，再补生活例子搭桥。不能先抛出“模型为什么偏向某类”等尚未建立对象的问题。多主题内容可以分段或设选读，但主题之间要有承接，不机械拆成许多独立小卡片。

需要训练复杂技能时，可采用“完整示范 → 补关键一步 → 独立变式”，三道题应训练同一种能力，不把不同子主题硬塞进这三个位置。自测可要求解释、计算、预测或辨错，读者应能判断自己是否真正学会。

文末串起整讲知识关系，按需要给出模型／方法比较、英文自测、配套任务和少量已有卡号，再提供来源索引。能合并的内容合并，不额外堆一遍与正文相同的总结。

### 2.3 讲人话，保留真正有用的细节

**“不讲废话、不要AI味”是内容验收要求。** 每句话应有具体作用：交代问题、解释概念、推进推理、演算例子、说明必要条件或给出可操作的方法。删去后不影响理解、条件和出处的句子，通常应删去或合并。

- 讲义像自然易读的教材；专业性通过准确的解释、条件和推理体现。先解释“哪些量一起变”“这个词出现几次”，再引入抽象名称。
- 一段集中说明一件事。避免一口气塞入主要结论、全部例外、实现细节和检查报告。标题应便于找到概念，少用连续的悬念问句或刻意俏皮的名称。
- 不用“这个概念非常重要”“这为我们提供了深刻洞见”等空泛评价代替解释。说明它在什么问题中有用、具体改变哪一步计算或判断。
- 避免连续套用“先……再……”“不是……而是……”或机械转场；避免反复自证“不冒充、不声称、不代做”。直接说明采用的条件与结论。
- 同一结论讲清一次即可。不要在开头预告、正文复述、段尾总结中反复换词说同一件事，也不要回答完一个问题后再附一段无关的泛泛提醒。
- 幽默或比喻应帮助理解具体机制；不为凑趣味加生硬笑话。类比有明显边界时就近说明。
- 版本盘点、构建次数、哈希保护、同步过程放维护记录。影响理解的模型差异、真实测量日期和实验限制仍放在相关解释旁。
- 困难步骤应展开，重复提醒应合并。没有统一删字比例、加例子数量或页数上限；微课的阅读时长估计不约束整讲讲义。
- 实现细节可以集中为选读，但理解公式所必需的符号、条件和推理不能移走。
- 精简重复不等于删掉独立题所需的条件。每道题被单独拿出来时仍要成立；题目让回忆某个公式时，不把该公式直接塞进题干泄露答案。

下面是判断写法的例子，仅示范表达方式，不作为新增课堂事实或修改源稿的指令：

| 容易造成阅读障碍的写法 | 我们采用的写法 |
|---|---|
| 开头直接问“为什么模型仍会偏向其中一台机器？” | 先交代要分辨什么、已有记录是什么、新样本是什么；读者理解任务后，再讨论两类证据为何不同。 |
| “A12给出先验，B4–15展示NB。” | 先解释先验在判断中起什么作用；随后用普通来源注写“Lecture2a，第12个单元”。 |
| 只写“累计词质量”而不解释 | 先说“把同一类文档里这个词的特征值加起来”；原始计数相加得到次数，TF-IDF输入相加得到权重，再连接公式。 |
| 只提醒“避免潜在数据泄漏” | 说明操作：“用训练集确定词表；验证集和测试集使用同一个词表做transform，不重新fit。” |
| 先展示压成一行的Python表达式 | 面向初学者先用多行for／if／return展示变量怎样变化，理解后再给紧凑写法。 |
| “没有手写一条看起来漂亮的路由。” | 保留实际观测日期、命令参数、输出和是否收到终点响应；删去作者自证。 |
| 每节都重讲“本资料不是官方答案、不能保证考试……” | 在统一说明中交代身份；具体题中只保留影响本题结论的来源差异和条件。 |

对比句本身可以有用，例如区分密度与概率、参数后验与类别后验；要避免的是套话和反复转折，而不是删除必要区别。

修改后连同前后文通读：这句话增加了什么信息？前面是否已经说过？抽象说法能否换成具体对象、动作或数字？去掉后是否仍然连贯？必要的过渡、推导、假设和例子要保留，不能把“去AI味”做成跳步、口水话或故意不专业。验收看阅读效果，不看AI检测器分数，也不按关键词一刀切删句。

### 2.4 数学、算例和实际结果

公式首次出现时说明变量含义、维度、单位、定义域、模型假设及用途；网络时序还要明确首位／整包、串行／流水线等约定。不要让同一字母在附近悄悄换含义。

补齐从直觉到推导的关键台阶，例如为什么相乘、为什么取log、对哪个量求导、矩阵形状如何匹配。必要时用小数字完整演算；再给同能力的独立变式，题目条件和关键答案齐全。综合题可以保留多个步骤，不机械切碎。

新算例、图中数字与关键推导须独立复算。绘图优先用NumPy、SciPy、Matplotlib等可复现工具，保留数据来源、参数和脚本。教师原题、教师解答、原Notebook保存输出、本次实测和整理者补充解释分别标明。

只修改Notebook说明时保留代码和执行输出，不因此重跑实验。改动代码、参数或计算时，运行受影响内容并保存真实结果；参考Notebook应能从干净内核顺序执行。检查数据形状、标签、种子、划分、预处理泄漏、单位和概率等关键性质。原文件输出不冒充本轮复现，大型搜索未重跑就如实说明。

### 2.5 中英文怎样配合

- 中文负责连续讲懂；保留老师英文标题及专业术语，首次出现给英文全称和缩写。
- 重要主题可有简短英文要点，注明是整理后的表达。中文串讲加英文摘要不称为“全文双语对照”，也不为形式翻译把篇幅翻倍。
- 练习题干、必要条件和关键答案中英对齐：对象、数字、单位、条件和结论相同。支持先用中文理解，再用英文独立解释与作答。
- 英文用自然技术英语，不逐字搬运中文修辞。原图、代码、文件名及数学符号保持准确，图的中文解释放在附近。

### 2.6 Tutorial、Assignment与Research Report

这些文档与Lecture／Chapter分开，围绕原任务展开，不另外强套生活故事：**完整原题与必要材料 → 对应知识 → 方法与关键步骤 → 输出或答案解释 → 本题的检查方法和易错点**。

- Tutorial按真实题号或任务顺序覆盖；一道自编例题不能代表整份Tutorial。题干依赖的数据、图、代码接口和约定必须齐全。
- 教师解答、同学作答和本次推导分开；原题歧义说明采用的条件。通用评估说明集中写一次，各题保留自己的限制。
- 编程参考笔记可从头运行；留给读者的练习不应阻断参考示范。结果来自实际运行，课堂反复比较测试集的任务标为探索，并解释训练内部验证的做法。
- 网络命令观察保留日期、参数、字段解释与实际结果。超时或未收到终点响应照实记录，不编造完整路由或测量。
- Assignment延续“纸笔详解，实验讲方案”：给任务拆解、基线、方法选择、验证、错误分析与复现指导。是否完成整个实验或生成正式提交文件，依当次用户授权，不能由整理讲义自动推定。
- Research Report指导选题、机制解释、证据、图示和实际反思；不编造个人经历。保留原任务要求的引用及AI使用说明。
- 截止日期、提交手续等放课程信息或链接原任务，不反复挤进技术正文。

### 2.7 可选基础补课

需要补课时，只默认读者会四则运算和简单方程。由函数、坐标、斜率等实际卡点逐步补到本讲需要的知识，不突然跳进log、梯度或矩阵推导。

有先修缺口的文档在开头放简短、可跳过的基础入口；正文第一次遇到卡点时直达相应专题。基础专题配自查题与答案，并提供带名称的返回链接，定位到原讲的具体步骤。无明显先修门槛时省略入口。

共用基础只维护一份，独立成册。基础页补先修；Bayes、Gram–Schmidt、SVM等课堂方法仍在所属Lecture／Tutorial中完整讲。Python与NumPy本身是Lecture 1内容，后续引用对应位置，不另抄一套。

图示要告诉读者“看哪里、说明什么”，坐标和单位齐全；静态图为默认，不另建账户、评分、错题本或复习排程。正式间隔复习继续交给Markji；本仓库不新增卡片、不生成APKG、不修改学习记录。

### 2.8 出处与重难点判断

正文先讲例子和推理，出处随后可查。不能以“A12、B4–15、S1”等内部简称开头，也不把小节第一行写成来源编号盘点。就近引用写完整名称，例如“来源：Lecture2a，第12个单元”；网络课注明文件／part和幻灯片序号。

Notebook单元号包含文字和代码，从原文件第一个单元按1计数，不是执行编号`In[n]`。逐文件核对简称映射，不做全库机械替换。文末覆盖索引给完整文件名、位置和本文章节。来源注使用能正常打印的正文格式，不能误用会被打印器隐藏的`.source-note`。

发现原件疑点时，记清原位置、问题、采用解释及依据；原件保持不变。必要的模型差异就近说明，详细核对过程放后部。

主要主题分别判断：

| 项目 | 写法 |
|---|---|
| 学习优先级 | 核心必会／常规掌握／二读拓展 |
| 理解难度 | 低／中／高，并说明真正卡在哪里 |
| 掌握要求 | 明确到解释、计算、推导、实现或迁移 |
| 判断依据 | 当前课件与任务、历史试卷、样题、教材／笔记、整理者建议分别记录 |

“难”不等于“考试重点”；必要基础即使未找到真题，也要讲清。优先级集中说明，正文只放必要短提示，避免每节重复长篇导读。

## 3. 编排与A4版式

### 3.1 理论在前，完整任务在后

每门课固定按 **Lecture／Chapter → Tutorial → Assignment／Research Report → 已完成映射的历史试卷附录** 排列。理论先排不意味着必须占全册一半页数。

各Lecture／Chapter、Tutorial、Assignment保持独立文档并独立起页；小节不必强制起页。课堂讲解中的小例题、随堂自测留在知识点附近。各讲文末保留配套任务链接；跨讲作业可从多处进入，但只维护一份。

文档登记表`learning/course-notes-documents.json`统一决定顺序。新增材料加入相应类别，不把Tutorial重新穿插回每一讲之间。基础继续独立成册，按需往返。

### 3.2 当前默认值与可读性原则

采用朴素白底单栏，以标题、段落和留白组织。不要把文章重新排成一块块卡片框，也不要为省页数把整册压成小字双栏。

当前打印实现的默认值如下；这是可依据实际PDF微调的基线，不是要求所有表格、图注和代码使用同一字号：

| 项目 | 当前默认 |
|---|---|
| 纸张与打印 | A4，100%实际大小，每张一页；双面建议长边翻转 |
| 页边距 | 上20 mm、下21 mm、左22 mm、右18 mm；左侧为装订与批注留白 |
| 正文 | 11 pt，1.25倍基线行距；Fandol中文、TeX Gyre Termes英文、newtx数学字体 |
| 表格与代码 | 按内容适度小于正文；不能靠缩小到难读来掩盖宽度问题 |
| 结构 | 清楚的标题层级、连续正文、适度视觉区分；提示不压过主线 |

### 3.3 图片与题图

图片按信息量采用正常合适的大小，不一律撑满版心。示意照片可以小；数据图缩小后坐标、图例和标签仍要读清。保留长宽比例，不拉伸或裁掉答题必要内容。

原页图带有大片纯白外边时，可在TeX排版时排除外边后再缩放，保留全部非白像素与安全边距；原图文件保持。逐张检查裁切后的题干、选项、坐标与标注，不能把题图文字连同原页白边一起缩得难读。

图放在解释到相关概念的位置，图注紧邻图片，并说明应观察什么。必要原题图在题目处可见，不能只在翻答案后出现，也不能写“见Tutorial那张图”却不给图。

宽幅原图、手写推导可按内容选择横向阅读或整页呈现。题图只提取必要区域；不带入学生姓名、学号、分数、手写答案或批改。不能为缩小图而失去标注或时序条件。

颜色编码的类别、正负权重等图需实际检查灰度效果。能用符号、线型或文字区分时同时提供；灰度会丢信息的图应说明建议彩印，不笼统保证全册黑白效果等同彩色。

### 3.4 公式与编号

- 独立展示的公式按讲次连续编号，便于纸上引用；行内变量与很短的行内算式不逐个编号。
- 同一个量的连续推导可沿等号对齐。左右长度差别很大的不同步骤，不机械追求同一等号列；可逐行居中，或拆成独立公式并加一句过渡。
- 以实际PDF中的视觉效果判断，不只看TeX源码。不能让对齐制造大片不均匀空白，也不能把长公式硬缩成很小的字。
- 长公式在有意义的步骤处分行；公式编号不碰正文或超出版心。相关步骤可用a/b子编号保留原引用，不让后面所有编号整体漂移。
- 公式、引导句和必要解释尽量放在相邻位置；不在符号定义前使用新符号，也不在跨页后留下孤立等号。

已确认的Lecture 2例子：式(2.6)逐行居中并适当增加行距；原式(2.21)分为(2.21a)、过渡说明和(2.21b)。这是按内容选择的排法，不是要求所有公式统一居中。已有其他编号及锚点保留，其他Lecture随实际修订逐步整理。

### 3.5 表格、代码、答案与分页

- 长表保留可读列宽、重复表头，避免一行被不合理拆开；过宽表可按列分面并保留对应行号。不能依赖横向滚动打印完整内容。
- 代码使用等宽字体，避免裁切；必要换行是打印处理，不改原Notebook运行代码。保留已执行输出和其解释。
- 打印版展开正文中的折叠答案和补充，检查答案、题图真的在输出中。短答案、短代码、图与图注、公式与引导句尽量避免不合理跨页。
- 不以大量空白换取所有段落强制整块不分页；保留自然阅读节奏，检查标题孤悬、页底短行及跨页条件。
- 正文段落至少保留两行相邻，不把末行的孤字留到下一页。公式前的引导句与公式保持同一段落，不用空行将两者断开；表格引导句与表头、首行留在同页。
- 检查TeX环境、公式、表格和答案是否完整。旧折叠答案迁为可打印的解答段；检查前后文及题图，不能只凭编译无报错认定内容完整。

### 3.6 目录、书签和纸质回链

保留既有文件名、锚点与链接身份。新增内容后重新计算目录、PDF书签、专题页码和跨册页码，直到分页稳定；纸面显示的页码与PDF点击目的地必须落到真正标题页，不能停在前一页的空锚点。

补课入口和返回位置除了电子链接，还应有可供纸读的分册／页码。对照最终PDF检查，不只检查链接字符串存在。PDF不依赖已删除的讲义网页，也不链接被Git忽略的HTML中间物。

公开文件不得出现机器私有路径或本机文件URI。需要引用本次新增仓库资料时，按贡献流程固定到已存在的源稿提交；三册之间保留有效的相对PDF链接。

## 4. 历史考试、考点提醒与两个索引

以下是已确认的编写规则。当前CS5489 Lecture 1–5已有逐讲历史考点映射；CS5222尚未建立考试统计。后续推广仍须逐讲核题，不能把本规范当作新讲次已审阅的证据。

### 4.1 先有可追踪台账，再有统计

长期台账记录：试卷身份、考试类型、年份与学期、文件版本与哈希、题号页码、对应考点、直接／关联考查、重复归属、答案来源及缺失条件。讲义开头、正文标记、讲末和卷末索引由同一台账生成，不能各自手填一组数字。

次数只按**独立试卷数**统计，不显示题目次数来代替：

- 同一考点在同卷有多题，只计一次；题号全部保留。
- 同题在不同已确认年份或学期再考，分别计入考试卷数；题集可以只收一次。
- 同卷的题纸、答案、扫描件、不同文件名或ZIP副本不重复计数。
- Semester A与B按不同学期登记，不当成同一场考试的A/B卷。
- 模拟题、样题单独标明，不计期中、期末或QE真题次数；同学笔记不增加次数。
- 后续聚类题使用高斯与协方差，记为关联考查，不合并成直接考查NB。
- 年份、科目、教师或校区有疑点时保留依据与不确定性；未知年份不猜填。无法确认独立原卷身份的QE片段写“年份未载／卷次待定”，不写成0次。

已知处理范例：2021B题纸封面写2020，结合题中指定答案文件和配套答案登记为“2021B*”并保留冲突；Mock复用2023A时保留入口但不增加真题次数。用户提供的CS5489 QE汇编按该身份收录，缺少的前页、年份与卷身份继续待补。

### 4.2 一讲开头：先给复习结论

在正式讲解前放简短的重要性概览：

**考点｜本轮复习重点｜期中卷数｜期末直接／关联卷数｜QE记录｜对应小节**。

区分多套卷直接考查的内容、支撑推导的基础、后续课程中的关联应用。给出复习动作，例如“能完整解释模型”“能比较假设”“能算后验”，而不只写“很重要”。

开头只放复习结论与简短口径，详细出处放后部，不把材料盘点塞进第一屏。不得写“每年必考”等预测。没找到题时写“现有材料未见”，不能据此说“不考”；一次出现不能写成高频。

### 4.3 正文小节：黑字标签与短色条

按2026-10-09确认的方案，使用黑字与左侧短实线色条的紧凑标签；2026-10-16迁入ElegantBook后取消装饰底框，保留文字类别和统计口径。相关小节标题后保留简短考点名称，再排列对应标签，不给正文整段上色。

| 色条 | 含义 | 标签文字示例 |
|---|---|---|
| 绿色 | 期中 | 期中 · 4套；需要时明确直接／关联 |
| 金黄色 | 期末 | 期末直接 · 1套；期末关联 · 3套 |
| 暗红色 | QE | QE题段 · 年份未载／卷次待定 |

同一考点的不同考试分别排标签，直接与关联记录不相加；长度不足时整体换行。文字承担全部含义，颜色只辅助分类，不表示复习优先级，黑白打印仍能辨认。未找到证据的类别不画空标签，也不把QE残题换算成0次或已确认次数。

标记必须对应实际考查能力。参数后验／MAP题不能直接标为“分类决策规则考过”；出现“高斯”一词也不足以证明整套Gaussian NB推导都考过。标签不取代解释、题号与依据。生成器、样式和验证细节见`docs/EXAM_LABEL_STYLE.md`。

### 4.4 讲末按考点，卷末按试卷

- **Lecture／Chapter末尾：** 按考点列年份学期、原题号、原材料页码、考试类型与直接／关联关系，以及要求解释、计算、比较还是推导。
- **课程分册最后：** 放在Assignment／Research Report之后，按每套试卷汇总本轮已经确认的相关题、答案来源和材料疑点。
- **原课覆盖索引继续保留：** 课堂来源索引负责回查老师讲过什么，考试索引负责回查哪套卷问过什么，不能合并替代。
- 索引明确映射范围，例如“本轮仅完成Lecture 2映射”；不能把其他Lecture或全学期写成已审阅。

### 4.5 独立期中题库与题答册

2026-10-10起，整理后的CS5489期中题目与答案解析以本仓库的[期中题库](../CS5489/exam-review/Midterm/README.md)（`CS5489/exam-review/Midterm/`）为唯一维护源。迁入前的Course期中题库只作历史快照，不再双向同步，也不从那里覆盖本仓库。

编辑`items/MTxxx/`中的TeX题答组件；各版本入口在`latex/books/`，导言和差异附录在题库`frontmatter/`。`QuestionIndex.json`维护题号、考点分组、出处、旧别名及题型。题目与答案解析分别生成A4 PDF，旧Markdown仅保留自动导航；合订本、精简双语版及选择题／简答题分册由同一组主稿自动生成，不单独维护另一套题答。各册独立分页，目录、书签与原卷索引按各自最终PDF生成，不能假设同题同页。

期中题目按考点与组内阅读顺序组织。每题保留稳定MT编号、完整英文原题、中文题意、必要数据与图及全部已确认出处；历史卷的规则不代表本学期考试安排。

同题只排一次，列出各年位置；选项、条件或要求有实质变化时保留不同版本。跨讲选择题保留完整题干与选项，再指出与本讲有关的部分，不能摘掉选项后改变原意。题目与答案用相同编号配对。

答案按“简洁完整的English answer → 逐点对应的中文答案 → 中文推理与关键计算 → 答案依据”组织。随卷答案、同学作答与本次复核推导必须区分；同学答案不能直接当标准答案。原答案有歧义或简化时，说明其条件，例如共享标量／共享对角方差、是否计入可学习先验的参数计数差别。

模拟专有题、期末题和QE题不混入期中题库。另行整理QE残题时，保留可读问法与出处，列清缺失的模型、先验、参数定义或数据。答案只给能确认的通用流程，不猜分布或具体结果；材料补齐后再升级为完整解答。

公开仓库可收录整理后的期中题答、必要的干净题图、来源与去重映射、勘误、构建校验工具及生成的PDF。完整原卷档案、学生手写答案与批注、个人提交文件仍由资料持有人另行保存，不加入Git。原始资料保持不变，公开文件不含姓名、学号、私人路径或凭证；普通构建与校验不依赖原卷，只有实际读取并核验归档后才能报告原卷核查。

## 5. 每轮修改、验收和协作

### 5.1 先记录，再修改

大规模修订先在`docs/reviews/<本轮>/`建立问题清单和基线。每项记录问题编号、文件与章节／Notebook单元、原文摘录、阅读障碍、处理办法、需保留的条件与出处、验收结果与状态。用锚点、标题和摘录定位，不只依靠会变化的行号。

每完成一份就更新进度，新发现先登记；没问题的段落明确记为保留。不要顺手修改任务范围外的Lecture、原材料、个人作业、卡片或网站。记录中的已完成、待核实、连接受阻必须与实际一致。

### 5.2 验收看什么

| 维度 | 必须核对的内容 |
|---|---|
| 教学 | 只看开头知道任务；术语先解释；关键步骤可复算；自测检验已经讲清的能力 |
| 表达 | 逐段检查空话、套话、同义复述、机械转场和无关提醒；删改后仍讲得顺，条件与推理完整 |
| 原课对应 | 当前版本、页码／单元与覆盖索引一致；题目条件、原图、符号、单位和代码约定保持 |
| 双语 | 题目对象、数字、条件和结论一致；英文足以独立作答 |
| 计算与运行 | 新算例独立复算；实际结果有运行依据；说明文字修改不动代码／输出 |
| 考试证据 | 每个卷数能追到去重后的卷和题号；直接、关联、样题、残题分开；题答逐项配对 |
| TeX与资源 | 公式、表格、折叠、图片、旧锚点与文件链接正常；不把源码无报错当成显示正常 |
| A4显示 | 新增和受影响页实际渲染查看；全页联系页看整体，放大检查公式、编号、长表、代码、题图和跨页处 |
| 彩色与灰度 | 标签黑字、边框与短色条清晰，直接／关联和待定状态完整；必要图例与数值可读 |
| 目录与回链 | 目录、书签、纸质页码和电子目的地都对应最终标题位置；跨册定位有效 |
| 范围与公开性 | 原材料及范围外正文保持；公开文件无整卷、个人信息与私有路径 |

打印交付检查最终PDF及电子链接、书签和文字提取。旧Markdown仅作导航，无需另外维护屏幕正文排版。没有进行实体打印时，只报告PDF／灰度渲染检查，不声称已验证真实纸张效果。

中文字体的字形与Unicode映射须随PDF嵌入，不能要求阅读器另装Adobe-GB1语言包。每页中文以独立解析器交叉核对，实际渲染再检查中文、公式与表格；渲染器报缺字体或映射时视为失败，不能换一个能显示的引擎后忽略报错。

按[贡献指南](../CONTRIBUTING.md)从主稿生成三册，稳定目录、书签和跨册页码，再运行仓库检查。构建与实验分开，失败时保留上一次验证过的PDF。只改本维护规范且不影响打印内容时，不需要重建三册。
