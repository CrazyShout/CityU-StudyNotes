## 典型前后对照

| 原来 | 修订后 |
|---|---|
| “二次项一正一负相减”后直接给SVM对偶 | 正则项、约束项和偏置项逐项代回；先合并1/2−1，再展开两个样本和的内积 |
| OLS说下一节解释斜率，下一节却直接进入矩阵 | 对截距求导→中心化残差→对斜率求导→同组三点的两条矩阵方程 |
| 核岭回归直接给a与预测公式 | 从Ridge驻点条件得到w=Phi a，再得到核矩阵方程与预测 |
| 反传先给转置，完整例子都是单位矩阵 | 逐分量展示两种求和；用非单位W实际得到隐藏梯度[1,−0.5] |
