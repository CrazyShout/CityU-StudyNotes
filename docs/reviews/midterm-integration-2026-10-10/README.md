## 内容处理

- 全部67题逐项对读题干与答案；保留清楚的解释，在41题中作定点修订，不用统一删字比例改稿。

- MT033用类别概率解释权重；MT046、MT047、MT059补密度、log、概率与sigmoid之间的运算步骤。
- MT043中文A去掉原文没有的条件；MT060区分原题图和答案草图、C=0端点与正向极限；MT061英文补全模型间存储排序。

首轮由三份独立审阅覆盖20、19、28题；修订后再次复查，并修正一处删除文字后留下的句末分号。逐题结果见[审阅表](REVIEW.md)。原英文题面、题号、原卷位置、旧别名与全部既有图片保持；中文题意只有MT043去增义一处调整，两册同步。
