本轮按Lecture2a/2b原顺序，将23个编号小节合成六个主题。原有锚点保留；核心讲解之后集中提供实现说明和来源索引。讨论与验收清单见[WORKLIST](WORKLIST.md)。

## 主要变化

| 原来 | 现在 |
|---|---|
| 写“图中空心方框”，正文却没有测试图 | 增加原划分的测试错误图，解释(4.7,3.2) cm为什么被错判 |
| 给出高斯参数，再直接给定另一个例题的密度 | 从5 cm代入密度，乘先验，再算到类别后验 |

| 每节重复来源、难度与要求 | 六主题正文，集中学习重点，保留节末短来源和完整覆盖索引 |
