# 原材料与引用

讲义按当前课程材料整理，引用中的Notebook单元包括文字和代码，从1开始计数；PPT按各原文件自己的幻灯片顺序计数。正文和文末索引保留材料名称与位置。

[原材料文件名与哈希](source-materials.json)用于确认下载版本。这里不收录原始整份Canvas课件、教材或历史资料库；原题图和必要教学插图作为讲义的一部分保留原作者出处。引用图和第三方内容的权利归原作者，本仓库不为其另行指定许可。

`vendor/katex`保留其原许可证。Notebook的输出来自记录的课堂实验；迁入时没有重新运行训练。

CS5489历史考点映射覆盖全学期Lecture 1–12：其中Lecture 1–5的逐卷证据台账保留在[Lecture2材料台账](../CS5489/course-notes/exam-evidence/Lecture02.json)及`Lecture01..05.json`，由`scripts/build_exam_annotations.py`统一生成正文标注与[全学期题源附录](../CS5489/course-notes/ExamIndex.md)；Lecture 6–12的期末与近年样题分布见各讲题源表及附录总表。原始扫描考卷与个人提交文件不随仓库发布；经重排核对的期中题库及两门课的期末双语合订本（[CS5489](../CS5489/exam-review/Final/CS5489-Final-Combined.pdf)、[CS5222](../CS5222/exam-review/Final/CS5222-Final-2021A-Combined.pdf)）均使用原创重绘示意图，历史题目不等于本学期考纲。
