# 原材料与引用

讲义按当前课程材料整理，引用中的Notebook单元包括文字和代码，从1开始计数；PPT按各原文件自己的幻灯片顺序计数。正文和文末索引保留材料名称与位置。

[原材料文件名与哈希](source-materials.json)用于确认下载版本。这里不收录原始整份Canvas课件、教材或历史资料库；原题图和必要教学插图作为讲义的一部分保留原作者出处。引用图和第三方内容的权利归原作者，本仓库不为其另行指定许可。

`vendor/katex`保留其原许可证。Notebook的输出来自记录的课堂实验；迁入时没有重新运行训练。

CS5489历史考点映射覆盖当前Lecture1–5。共享试卷身份、来源哈希和去重规则保留在[Lecture2材料台账](../CS5489/course-notes/exam-evidence/Lecture02.json)，其他Lecture台账引用同一身份；正文标注和[按卷索引](../CS5489/course-notes/ExamIndex.md)由`scripts/build_exam_annotations.py`统一生成。原卷、扫描批注和完整私人题答不随仓库发布；题目摘要不等于官方考纲。
