\textbf{A and D.} A generative classifier models \(p(x\mid c)\) and the class prior \(p(c)\). It predicts using \(p(c\mid x)\propto p(x\mid c)p(c)\), so maximizing only the class-conditional density is generally insufficient. Priors can encode prior information, and the construction extends to multiple classes.
