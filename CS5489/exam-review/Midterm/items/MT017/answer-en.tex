\textbf{A, B and C in the supplied key.} For Gaussian NB, shared class variances cancel the quadratic terms, giving a linear boundary; class-dependent variances generally leave quadratic terms. RBF SVMs and stump ensembles can represent simple separating surfaces as well as nonlinear ones.


D uses a \textbf{homogeneous} degree-2 kernel: its explicit features contain quadratic products, but no first-order terms. It does not supply the general affine boundary family. Do not replace it with \((x^Tx'+1)^2\), which is a different kernel. E remains linear in the given features; changing the regularization strength does not introduce nonlinear features.
